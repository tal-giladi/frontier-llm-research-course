- **Superposition** — a model representing more features than it has dimensions by giving sparse features overlapping directions, accepting interference when they are active together (Elhage et al. 2022). [17.1]
- **Feature dimensionality** — D_i = ‖W_i‖⁴ / Σ_j (Ŵ_i · W_j)²: 1 for a feature with a dimension to itself, 1/2 for an antipodal pair, 2/5 for a pentagon. [17.1]
- **Sparse autoencoder (SAE)** — a wide encoder-decoder trained to rewrite an activation as a sparse, non-negative combination of learned directions (the decoder rows) plus an error. [17.1]
- **Latent** — one entry of an SAE's code; its decoder row is the direction it writes. [17.1]
- **TopK SAE** — an SAE that keeps the k largest pre-activations per token and zeroes the rest, so L0 = k by construction (Gao et al. 2024). [17.1]
- **JumpReLU SAE** — an SAE whose latents pass their pre-activation only above a learned per-latent threshold, trained with an L0 penalty and straight-through estimators (Rajamanoharan et al. 2024). [17.1]
- **Shrinkage** — the downward bias an L1 sparsity penalty puts on the codes of active latents. [17.1]
- **Straight-through estimator (STE)** — a pseudo-gradient used in place of the zero-almost-everywhere gradient of a step function; JumpReLU uses a rectangle kernel of bandwidth ε. [17.1]
- **AuxK loss** — an auxiliary TopK-SAE loss that reconstructs the residual error from the top dead latents, keeping them alive. [17.1]
- **Dead latent** — a latent that never fires on held-out tokens. [17.1]
- **FVU (fraction of variance unexplained)** — Σ‖x − x̂‖² / Σ‖x − x̄‖²; also called normalised MSE. [17.1]
- **L0** — the mean number of active latents per token. [17.1]
- **Delta loss (spliced loss)** — the increase in next-token loss when an SAE's reconstruction replaces the activation in the forward pass. [17.1]
- **Splice check** — running the model with x̂ + (x − x̂) spliced in and confirming the loss is unchanged, before trusting any SAE measurement. [17.1]
- **Loss recovered** — (L_ablated − L_spliced) / (L_ablated − L_clean); depends on the ablation used as reference. [17.1]
- **Activation patching** — copying an activation from one run (clean or corrupt) into another and measuring the change in a behavioural metric. [17.2]
- **Denoising** — patching clean activations into a corrupt run; tests whether a component is sufficient to restore the behaviour. [17.2]
- **Noising** — patching corrupt activations into a clean run; tests whether a component is necessary on the distribution. [17.2]
- **Logit difference** — logit of the correct answer minus logit of the contrast answer at the prediction position; the default patching metric. [17.2]
- **Symmetric token replacement** — making the corrupt prompt by swapping tokens (names, subjects) rather than adding noise, so it stays in distribution. [17.2]
- **Normalised patching effect** — the metric change from a patch divided by the mean clean-corrupt gap: 0 = no effect, 1 = full effect. [17.2]
- **Path patching** — patching a sender's change along the direct path into one receiver only (a later head's query, key or value, an MLP input, or the logits) (Wang et al. 2022). [17.2]
- **Q-, K-, V-composition** — a later attention head reading an earlier head's output through its queries, keys or values (Elhage et al. 2021). [17.2]
- **Previous-token head** — an attention head that writes the identity of the preceding token into each position. [17.2]
- **Induction head** — a head that attends from a token A to the token after an earlier A and copies it; built by K-composition with a previous-token head (Olsson et al. 2022). [17.2]
- **Attribution patching** — the first-order estimate (a_clean − a_corrupt) · ∂m/∂a of a patching effect from one forward and one backward pass; a screen, not a measurement. [17.2]
- **Mean ablation** — replacing an activation with its mean over a reference distribution (for IOI, the ABC distribution). [17.2]
- **Resample ablation** — replacing an activation with its value on another random prompt; the basis of causal scrubbing. [17.2]
- **Random-component control** — ablating random sets of components of the candidate's size; the candidate's rank p-value is (1 + #{random ≥ candidate}) / (1 + n). [17.2]
- **Random-direction control** — projecting out random unit directions in the same site to calibrate a direction-level effect. [17.2]
- **Off-target check** — measuring an intervention's effect on ordinary next-token loss or an unrelated task, to tell a specific effect from breaking the model. [17.2]
- **Faithfulness, completeness, minimality** — the IOI paper's criteria for a circuit: it reproduces the model's metric alone, removing parts of it acts like removing them from the model, and every part matters for some subset. [17.2]
- **Interpretability illusion (subspace)** — a subspace patch that changes behaviour by activating a dormant parallel pathway rather than the one the model uses (Makelov et al. 2023). [17.2]
- **Transcoder** — a sparse stand-in for an MLP that reads the MLP input and predicts its output. [17.3]
- **Cross-layer transcoder (CLT)** — a transcoder whose features read the residual stream at one layer and write to the MLP outputs of that layer and all later ones. [17.3]
- **Replacement model** — the model with every MLP replaced by its transcoder. [17.3]
- **Local replacement model** — for one prompt, the replacement model with attention patterns and normalisation denominators frozen and error nodes added, so it reproduces the original logits exactly and is linear between features. [17.3]
- **Error node** — the difference between an MLP's output and its transcoder's output at one position, held fixed in the local replacement model. [17.3]
- **Attribution graph** — nodes for embeddings, active features, error nodes and top logits; edges are direct linear effects a_s · ∂input_u/∂a_s in the local replacement model. [17.3]
- **Graph pruning** — keeping the nodes with the largest total influence on the logits, B = (I − Â)⁻¹ − I over the row-normalised absolute edges, up to a cumulative share. [17.3]
- **Error share** — the fraction of the logit influence that flows from error nodes; a measure of how much of a graph the dictionary does not explain. [17.3]
- **Steering vector** — a residual-stream direction added with a coefficient α to change a behaviour. [17.4]
- **Contrastive activation addition (CAA)** — a steering vector computed as the mean activation difference at the answer letter between A/B items answered with and without the behaviour (Panickssery et al. 2023). [17.4]
- **Persona vector** — a direction for a character trait extracted from contrastive system prompts and judged responses, used for monitoring, steering and data flagging (Chen et al. 2025). [17.4]
- **Dose response** — the behavioural effect of a steering vector as a function of α, with intervals. [17.4]
- **Shuffled-label control** — the same difference-of-means estimator with the trait labels permuted; what the vector looks like by chance. [17.4]
- **Preventative steering** — adding the trait vector during fine-tuning so the fine-tune does not have to move the model along it (Chen et al. 2025, section 5.2). [17.4]
- **Weight-sparse transformer** — a transformer trained so that all but the largest-magnitude entries of each weight matrix are zero after every step (Gao et al. 2025). [17.5]
- **Circuit pruning (learned masks)** — finding the fewest nodes that keep a task's loss below a target, with the removed nodes mean-ablated. [17.5]
- **Concept injection** — adding a concept vector to the residual stream and asking the model whether it notices an injected thought (Lindsey 2025). [17.5]
- **Claim card** — the module project's record of one causal claim: scope, effect with interval, control and its p-value, held-out effect, off-target change and limitations, checked mechanically. [17.P]
