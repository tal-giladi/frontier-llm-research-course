# Module 11 quiz — What will the big run do?

This quiz checks the decisions of Module 11 in realistic situations: choosing a model size and token count for a budget, reading a scaling-law fit and its constants critically, pricing over-training and repeated data, predicting a downstream metric from loss and telling real emergence from a metric artefact, and building, pre-registering and monitoring a ladder before an expensive run. It has 10 multiple-choice questions; the pass mark is 70%.

It covers the three lessons of the module:

- [11.1 · Compute-optimal and over-trained regimes](../lessons/module-11/lesson-01.md)
- [11.2 · Predicting downstream capability](../lessons/module-11/lesson-02.md)
- [11.3 · De-risking a run](../lessons/module-11/lesson-03.md)

The module's practical assessment is the [Recipe-R run project](../projects/module-11-recipe-r.md).
