# Research note: QK-Clip beats QK-norm

*A fictional internal note for lab 19.3. The runs behind it exist only as the EXAMPLE run cards in `cards/`, and
every number is invented. Review it with the template in `../review-template.md`; do not edit this file.*

## Summary

We replaced QK-norm with QK-Clip ($\tau = 15$) in the toy model trained with Muon at learning rate 1e-2. QK-Clip
reaches a held-out loss of **6.268** against QK-norm's **6.302**, a 0.034-nat improvement, and keeps the maximum
attention logit bounded. QK-Clip beats QK-norm, and the gain should transfer to frontier models, where Kimi K2 needed
it. We recommend QK-Clip instead of QK-norm for the Recipe-R run.

## Setup

- Both arms: toy preset (1.8M parameters), Muon with AdamW for embeddings and norms, learning rate 1e-2, cosine with
  50 warm-up steps, Data-v0 at the CPU size, seed 0.
- QK-Clip arm (`clip-s0`): QK-norm off, QK-Clip with $\tau = 15$. QK-Clip was still improving at 300 steps, so we let
  it continue to 400 steps.
- QK-norm arm (`norm-s0`): QK-norm on, no clip, 300 steps.
- Evaluation every 50 steps on 256 windows of the test split. We report the best evaluation of the QK-Clip run
  (step 250) and the final evaluation of the QK-norm run.

## Result


*Figure 1. Held-out loss of the two runs against optimizer step. QK-Clip is lower from step 150 on.*

The difference of 0.034 nats is larger than the 0.02 nats we usually consider meaningful, so the improvement is real.
The maximum attention logit of the QK-Clip run stayed near 15 for the whole run, as designed.
